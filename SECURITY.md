# Segurança

O GeoLume está em desenvolvimento. Não use este repositório para enviar credenciais, tokens, arquivos `.env.local`, dados de clientes ou informações pessoais.

## Relatando uma vulnerabilidade

Não abra uma issue pública com detalhes de uma vulnerabilidade.

Use a opção de **Security Advisories** do GitHub, quando disponível, para enviar o relatório de forma privada. Inclua:

- descrição do problema;
- passos para reproduzir;
- impacto provável;
- versão ou commit afetado;
- sugestão de correção, se houver.

Até que o problema seja corrigido, evite divulgar detalhes publicamente.
